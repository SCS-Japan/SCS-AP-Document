# SCS評価制度 文書アーカイブ

IPA「サプライチェーン強化に向けたセキュリティ対策評価制度（SCS評価制度）」の公開ページと文書を毎日取得し、過去の版とあわせて保管するアーカイブです。

> 出典：独立行政法人情報処理推進機構（IPA）[SCS評価制度](https://www.ipa.go.jp/security/scs/index.html)
> 本リポジトリは非公式のアーカイブです。正式な情報は必ず公式サイトで確認してください。

## このリポジトリについて

| 項目 | 内容 |
|---|---|
| 取得中のページ | {{pages}} ページ |
| 取得中の文書 | {{documents}} 件 |
| 最後に変更を検知した日 | {{last_change}} |
| 最終確認日 | {{checked}} |

| フォルダ | 中身 |
|---|---|
| [`documents/`](documents/) | 最新版。`<分類>/<ページ名>.md` にページ本文、`<分類>/<ページ名>/` に資料の原本（PDF・Word・Excel など）とテキスト版 |
| [`archive/`](archive/) | 過去の版。`<分類>/<検知日>_<ファイル名>` で保存 |
| [`history/`](history/) | 更新履歴。[CHANGELOG.md](history/CHANGELOG.md)（差分つき）、[documents.md](history/documents.md)（取得対象と過去の版の一覧）、`diffs/`（差分）、`catalog.json`（台帳） |
