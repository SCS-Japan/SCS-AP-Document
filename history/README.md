# 更新履歴

SCS評価制度の公開ページや資料について、「いつ変更を確認したか」「どこが変わったか」を調べるためのフォルダです。

## 更新履歴の見方

- **最近の変更を知りたい** → [更新履歴](CHANGELOG.md)
- **資料を探したい・過去の版を見たい** → [ページと文書の一覧](documents.md)
- **最新の資料を読みたい** → [公開資料フォルダ](../documents/)

## このフォルダにあるもの

| ファイル・フォルダ | 内容 |
|---|---|
| [CHANGELOG.md](CHANGELOG.md) | 公式サイトのお知らせと、本リポジトリで検知した変更を確認できます。 |
| [documents.md](documents.md) | 収集対象のページ・資料の一覧です。最新の資料や過去の版へのリンクがあります。 |
| [diffs/](diffs/) | 前の版から追加・削除された文章を記録した差分ファイルです。 |
| [catalog.json](catalog.json) | 取得元のURL、取得日、保存先などをまとめた、プログラム向けの管理データです。通常の閲覧では開く必要はありません。 |

## 変更内容の確認方法

1. [更新履歴](CHANGELOG.md) を開きます。
2. 確認したい日付・資料を探します。
3. **「差分を表示」** を開くと、前の版から変わった箇所を確認できます。

履歴内のリンクから、資料の原本や Markdown 版、差分ファイルも開けます。

### 差分の読み方

差分では、行の先頭の記号で変更内容を示しています。

- `-`：前の版から削除された行
- `+`：新しい版で追加された行
- 記号なし：変更箇所の前後にある、変更されていない行

例えば、次の差分は「軽減」が「低減」に変更されたことを表します。

```diff
- 脆弱性悪用のリスクを軽減する対策を実施している。
+ 脆弱性悪用のリスクを低減する対策を実施している。
```

> `---` と `+++` で始まる行は、比較するファイルの名前です。本文の削除・追加ではありません。

## 過去の資料を確認する方法

[ページと文書の一覧](documents.md) から対象の資料を探し、過去の版へのリンクをたどってください。

保存場所を直接確認したい場合は、[過去の版フォルダ](../archive/) を参照してください。

## 履歴を見るときの注意点

### 履歴の日付と、公式の更新日は異なる場合があります

本リポジトリで変更を確認した日と、IPAが資料を公開・更新した日は、必ずしも同じではありません。

公式の公開日・更新日を確認したい場合は、資料の原本や公式サイトをご覧ください。

### 「最新バージョン」は、公式のバージョン番号とは限りません

一覧に表示される「最新バージョン」は、資料のファイル名に含まれる「v1.0」「v1.1」などのバージョン表記です。
バージョン表記がない資料は、ファイルの最終更新日（yyyy-mm-dd）を表示します。

公式のバージョン番号が変わらなくても、内容が修正される場合があります。

### 差分だけでは判断できない変更もあります

差分は、ページ本文や資料をテキスト化した内容の比較です。

改行や空白の違いが変更として表示されることがあります。
一方で、図・レイアウト・Excelの書式などの変更は、差分では十分に確認できない場合があります。

重要な変更については、必ず変更前後の原本を確認してください。

### すべての更新を網羅するものではありません

履歴は、本リポジトリで取得・確認できた範囲の記録です。
収集開始前の変更や、取得と取得の間に行われた変更など、記録されていない更新がある可能性があります。
