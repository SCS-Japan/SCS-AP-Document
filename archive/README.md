# 過去の資料

SCS評価制度の公開ページや資料について、本リポジトリで保存している過去の版をまとめたフォルダです。

以前の記載を確認したり、更新前後の内容を比較したりするときに利用できます。

> **このフォルダの資料は、最新版ではありません。**
> 現在の要求事項の確認や評価・申請には、[IPA公式サイト](https://www.ipa.go.jp/security/scs/index.html) の最新情報を使用してください。
> 本リポジトリの最新取得版は、[公開資料フォルダ](../documents/) にあります。

## アーカイブの見方

- **特定の資料の過去の版を探したい** → [ページと文書の一覧](../history/documents.md)
- **いつ・どこが変わったか知りたい** → [更新履歴](../history/CHANGELOG.md)
- **最新の資料を読みたい** → [公開資料フォルダ](../documents/)

## 過去の資料の探し方

1. [ページと文書の一覧](../history/documents.md) を開きます。
2. 確認したいページや資料を探します。
3. 「過去の版」の欄から、対象の資料を開きます。

ファイルを直接探すよりも、一覧から探すと資料名やバージョンの情報を確認しやすくなります。

## このフォルダにあるもの

過去の版は、[`documents/`](../documents/) と同じ分類（掲載ページを単位にしたフォルダ）で分けています。

| 内容 | 保存先 | 主な用途 |
|---|---|---|
| 過去のページ本文 | `<分類>/<検知日>_<ページ名>.md` | GitHub 上での閲覧、文字列検索、変更内容の比較 |
| 過去の資料（原本） | `<分類>/<ページ名>/<検知日>_<ファイル名>` | 正確な記載、図表、様式などの確認 |
| 過去の資料（テキスト版） | `<分類>/<ページ名>/<検知日>_<ファイル名>.md` | 文字列検索、変更内容の比較 |

### 原本と Markdown の使い分け

**文章を読んだり検索したりする場合**は、Markdown 版が便利です。

**正式な記載や図表、レイアウトを確認する場合**は、原本を参照してください。
Markdown 版では、表・図・注記・Excel の書式などが正確に再現されない場合があります。

なお、Webページの本文は Markdown 版を参照してください。

## 保存場所とファイル名

`documents/` と同じ分類フォルダの中に、資料ごとのフォルダを作り、その中に検知日を付けて保存しています。

ファイル名の基本形：

```text
資料：<分類>/<ページ名>/<検知日>_<ファイル名>
ページ：<分類>/<検知日>_<ページ名>.md
```

保存例：

```text
archive/
├── scs/
│   ├── 2026-10-28_faq.md                                    # 過去のページ本文
│   ├── 2026-10-29_requirements-criteria.md
│   └── requirements-criteria/
│       ├── 2026-10-28_SCS-400-criteria-v1.1.xlsx            # 過去の原本
│       ├── 2026-10-28_SCS-400-criteria-v1.1.xlsx.md         # そのテキスト版
│       ├── 2026-10-28_SCS-410-self-assess-guide-v1.0.pdf
│       └── 2026-10-28_SCS-410-self-assess-guide-v1.0.pdf.md
└── choutatsu/
    └── koubo/
        └── 2026/
            └── koubo20260626/
                └── 2026-10-28_koubo20260626.pdf
```

> ファイル名の日付は、本リポジトリが変更を検知した日です。IPAによる公式の公開日・更新日と一致するとは限りません。
> 日付やバージョンの詳細は、[ページと文書の一覧](../history/documents.md) や資料の原本で確認してください。

## 更新前後を比較したいとき

[更新履歴](../history/CHANGELOG.md) から対象の資料を探し、**「差分を表示」**を開くと、前の版から追加・削除された文章を確認できます。

差分の詳しい読み方は、[更新履歴の案内](../history/README.md) を参照してください。

図・レイアウト・書式などの変更は、テキストの差分だけでは確認できない場合があります。
重要な変更については、変更前後の原本を比較してください。

## 利用するときの注意点

### 過去の内容であることを確認してください

このフォルダには、修正前の記載や、現在は使用されていない様式が含まれる場合があります。

資料を引用・共有するときは、過去の版であることが分かるように、日付やバージョンの情報を添えてください。

### 公式のバージョン番号が同じでも、内容が異なる場合があります

「v1.0」「v1.1」などのバージョン番号が変わらないまま、記載が修正される場合があります。

本リポジトリでは、同じバージョン番号のまま内容が変わった場合も、検知日を付けて別の版として保存します。
ファイル名のバージョン番号だけで判断せず、検知日や履歴、原本の内容も確認してください。

### すべての過去の版を保存しているわけではありません

ここにあるのは、本リポジトリで取得・保存できた資料です。

収集開始前の版や、取得と取得の間に公開・差し替えされた版など、保存されていない資料がある可能性があります。

### 資料の利用条件を確認してください

本リポジトリへの保存は、各資料の権利や利用条件を変更するものではありません。

転載・再配布等にあたっては、公開元の利用条件および各資料の記載を確認してください。
