第1章    はじめに

1.1   本ガイドの位置づけ

本ガイドは、「サプライチェーン強化に向けたセキュリティ対策評価制度」（以下「SCS 評
価制度」又は「本制度」という。）における★3 又は★4 の登録希望組織又は登録組織が行
う取得単位及び適用範囲の決定、同組織が行う自己評価、並びに★3 確認責任者等が行う確
認に関する手続きを示すものである。

1.2   用語定義

本ガイドで使用する用語は、特段の定めがない限り、「サプライチェーン強化に向けたセキ
ュリティ対策評価制度（SCS 評価制度）基本規程」（以下「基本規程」という。）において
使用する用語による。
なお、本ガイドにおいて、「文書」
               「記録」
                  「台帳」
                     「一覧」「申請・承認」には、情報システ
ム上の設定、登録情報、ワークフローの記録、ログ、管理ツール及びそれらの画面表示や出
力（スクリーンショット、CSV 等）を含む。


第2章    取得単位及び適用範囲の決定

2.1   取得単位及び適用範囲の決定に係る実施プロセス

登録希望組織は、自己評価等に先立ち、取得単位及び適用範囲を自らの責任と判断において
あらかじめ定める必要がある。取得単位及び適用範囲の考え方、設定事例については、
「★3・★4 要求事項・評価基準 解説書」の第 3 章を参照されたい。
2.2 に示す通り、原則として、取得単位は法人又は個人事業主単位とする。事業部単位、企
業グループ単位など取得単位を法人単位としない場合は、取得単位について、★3 確認責任
者又は評価機関による妥当性の確認を受ける必要がある。また、登録希望組織は、取得単位
に基づき設定した適用範囲について、★3 の登録に際しては★3 確認責任者、★4 の登録に
際しては評価機関による妥当性の確認を受ける必要がある。
登録希望組織は、取得単位及び適用範囲について、★3 の登録に際しては★3 確認責任者、
★4 の登録に際しては評価機関との間で合意した場合、文書確認等の後続の段階へ進むこと
ができる。



2.2   ★3 確認責任者又は評価機関による妥当性の確認を要する事項

第3章    アセスメントシート等の取扱い

3.1   アセスメントシートの位置づけ及び見方

3.1.1 アセスメントシートの位置づけ

登録希望組織は、要求事項・評価基準に対する遵守状況の自己評価を行い、★3 の登録にあ
たっては★3 確認責任者による内容の確認を、★4 の登録にあたっては評価機関による内容
の確認を受ける必要がある。
自己評価の実施にあたって、登録希望組織は、本ガイド別紙「自己評価における適合基準
等」に示す【自己評価方法】を参照し、要求事項・評価基準の遵守状況を確かめる必要があ
る。アセスメントシートとは、当該自己評価等の実施において、登録希望組織が作成する自
己評価結果を記入する様式である。自己評価等における本シートの利用は任意とするが、自
己評価等の実施にあたって準備すべき証跡やその他必要な情報等を事前に網羅的に把握する
ため、利用を推奨するものとする2。登録希望組織は、IPA の SCS 評価制度公式サイト
（https://www.ipa.go.jp/security/scs/index.html）より後述する事項があらかじめ記載され
たアセスメントシートのテンプレートをダウンロードすることができる。
★3 の取得にあたって、登録希望組織は、自組織内又は外部の★3 確認責任者に記入したア
セスメントシート等3の確認を依頼する。依頼を受けた★3 確認責任者は受領したアセスメ
ントシート等に必要事項がもれなく記載されているか及びその内容が妥当であるかを確認
し、必要に応じて助言を行う。確認の結果、適用される全ての★3 要求事項・評価基準を満
たしていると判断した場合は、★3 確認責任者は、受領したアセスメントシートに対して所
定の確認を行った証として署名又は記名を行う。
★4 の取得にあたっては、アセスメントシート等の確認を評価機関に依頼する必要がある。
依頼を受けた評価機関は、アセスメントシート等に必要事項がもれなく記載され、かつ記載
内容が妥当であるかを確認することにより、「文書確認」を行う。
なお、制度運営機関が提供するアセスメントシートを使用せず、独自の様式を用いて自己評
価等を実施することも妨げないが、その際、当該様式は、アセスメントシートに含まれる各
項目（以下に示すとおり）を含むものでなければならない。
    ① 要求事項・評価基準
    ② 各評価基準の内容が適用対象外となるかどうか及び適用対象外とする場合の理由を記
      入する欄
    ③ 各評価基準への自己評価結果（適合/不適合）を記入する欄
    ④ アセスメントシートに記載されたものと同一の質問事項（「適用範囲に係る質問事
      項」を含む。）及び質問事項への回答欄

3.1.2 アセスメントシートの見方

本ガイドにおいて様式として定めるアセスメントシートは、登録を希望する段階ごとに★3
用と★4 用の 2 種類に分かれている。
アセスメントシートの構成は、★3・★4 で同一であり、大きく分けて以下 5 つの部分に分
かれる。
