# 要求事項・評価基準

公開日：2026年4月21日

最終更新日：2026年10月29日

本ページでは、SCS評価制度の★3・★4要求事項・評価基準および評価実施に関するガイド、解説書等を掲載しています。
★3・★4登録希望組織や評価機関等の皆様には、各資料をご覧いただき、SCS評価制度の評価の考え方の理解にご活用ください。
要求事項・評価基準、ガイド、解説書等の位置づけや、想定読者については、「要求事項・評価基準、ガイド、解説書等の位置づけ」をご確認ください。
★3・★4の詳細は「段階別評価の概要」をご確認ください。

- [要求事項・評価基準、ガイド、解説書等の位置づけ(PDF:623 KB)](https://www.ipa.go.jp/security/scs/rcu1hd0000007a2i-att/SCS-documents-overview.pdf)
- [段階別評価の概要](https://www.ipa.go.jp/security/scs/details.html#dannkai)

## 要求事項・評価基準

**文書名**

- SCS-400
- [★3・★4 要求事項・評価基準(Excel:42 KB)](https://www.ipa.go.jp/security/scs/rcu1hd0000007a2i-att/SCS-400-criteria-v1.1.xlsx)

更新日：2026年10月29日

**概要**

本書は、登録希望組織が登録を受けるためのセキュリティ要件である「要求事項」及び評価に際して要求事項を満たしていると判断する基準である「評価基準」を定める。

- [変更箇所（2026年10月28日公開版と2026年3月27日公開版の差異）(PDF:1.3 MB)](https://www.ipa.go.jp/security/scs/rcu1hd0000007a2i-att/SCS-criteria-comparison.pdf)

## 評価用ガイド

**文書名**

- SCS-410
- [★3・★4 自己評価等ガイド(PDF:1.3 MB)](https://www.ipa.go.jp/security/scs/rcu1hd0000007a2i-att/SCS-410-self-assess-guide-v1.0.pdf)
- 更新日：2026年10月29日

**概要**

本ガイドは、★3又は★4の登録希望組織又は登録組織が行う取得単位及び適用範囲の決定、同組織が行う自己評価、並びに★3確認責任者等が行う確認に関する手続きを示すものである。

- 関連資料：
  自己評価で用いるアセスメントシート（テンプレート）を以下に掲載する。
- [★3・★4 自己評価等ガイド 別紙\_アセスメントシート(Excel:134 KB)](https://www.ipa.go.jp/security/scs/rcu1hd0000007a2i-att/SCS-410AP-self-assess-sheet-v1.0.xlsx)
- 更新日：2026年10月29日

**文書名**

- SCS-420
- [★4 第三者評価ガイド(PDF:1.2 MB)](https://www.ipa.go.jp/security/scs/rcu1hd0000007a2i-att/SCS-420-3rdparty-assess-guide-v1.0.pdf)
- 更新日：2026年10月29日

**概要**

本ガイドは、SCS評価制度において評価機関が行う★4の第三者評価に関する手続きを示すものである。

**文書名**

- SCS-430
- [★4 技術検証ガイド(PDF:739 KB)](https://www.ipa.go.jp/security/scs/rcu1hd0000007a2i-att/SCS-430-vuln-assess-guide-v1.0.pdf)
- 更新日：2026年10月28日

**概要**

本ガイドは、SCS評価制度において評価機関及び技術検証事業者が行う★4の技術検証に関する手続き、並びに登録希望組織又は登録組織が★4の技術検証に対応する際の留意事項を示すものである。

## 解説書

**文書名**

- SCS-620
- [★3・★4 要求事項・評価基準 解説書(PDF:2.0 MB)](https://www.ipa.go.jp/security/scs/rcu1hd0000007a2i-att/SCS-620-handbook-v1.0.pdf)
- 更新日：2026年10月28日

**概要**

本解説書は、★3・★4 要求事項・評価基準に関して、登録希望組織又は登録組織が取得単位や適用範囲の設定、自己評価等を適切に実施できるよう、その考え方や留意点を解説するものである。
