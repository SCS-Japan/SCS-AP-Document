# 評価機関・技術検証事業者・研修事業者 新規申請事業者向け説明会

公開日：2026年8月31日

最終更新日：2026年10月26日

2026年度の説明会、アーカイブ配信は終了しました。

## 開催案内

IPAでは、SCS評価制度の運用開始に向けて、評価機関、技術検証事業者及び研修事業者として制度への参画をご検討されている事業者を対象としたオンライン説明会を開催いたします。
（注釈）本説明会では、SCSセキュリティ専門家になりたい方や、★3・★4取得希望組織向けの説明はございません。

## オンライン説明会の概要

**開催日時**

- 【午前の部：評価機関・技術検証事業者様向け】
  2026年9月14日（月曜日）10時30分～12時00分（開催終了）
- 【午後の部：研修事業者様向け】
  2026年9月14日（月曜日）13時30分～14時30分（開催終了）
- 【アーカイブ配信：評価機関・技術検証事業者様向け】
  - 2026年9月18日（金曜日）～2026年10月26日（月曜日）
- 【アーカイブ配信：研修事業者様向け】
  - 2026年9月18日（金曜日）～2026年10月26日（月曜日）

**参加費**

無料

**対象者**

評価機関、技術検証事業者、研修事業者として申請をご検討されている事業者様

**内容**

- 指定に係る制度規定の説明
- 第1回公募に関する説明
