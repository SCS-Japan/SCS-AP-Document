 SECURITY ACTION 制度
「SECURITY ACTION」は、中小企業自らが情報セキュリティ対策に取り組むことを自己宣言する
 制度です。SECURITY ACTION は取組み目標に応じて一つ星・二つ星があります。SCS 評価制度の
 ★3・★4 取得に向けた第一歩として、まずは SECURITY ACTION の自己宣言の一つ星・二つ星から
 始めましょう。
                      https://www.ipa.go.jp/security/security-action/

 サイバーセキュリティお助け隊サービス ( 新類型 )
SCS 評価制度の制度創設に合わせて、   ★3・★4 取得を目指す中小企業に向けて、                   セキュリティ対策の
実施状況を診断し、  未達成項目の解消に向けて伴走支援する民間事業者提供サービスの創設が
検討されています。
                https://www.meti.go.jp/policy/netsecurity/otasuketai_jissho.html

中小企業の情報セキュリティ対策ガイドライン
本ガイドラインは、中小企業が情報セキュリティ対策に取り組む際の指針や実践手順を
まとめたもので、第 4.0 版では SCS 評価制度の基本的な考え方を反映しています。
付録 5「情報セキュリティ関連規程（サンプル）    」は、SCS評価制度の★3・★4 の要求事項に
対応し、SCS評価制度の要求項目との対応表も掲載しています。

                         https://www.ipa.go.jp/security/guide/sme/about.html

中小企業向けサイバーセキュリティ対策支援者リスト
本リストは、国家資格「情報処理安全確保支援士（登録セキスペ）  」の有資格者のうち、
中小企業向けにサイバーセキュリティ対策を支援できる専門家の一覧です。相談先を
お探しの際にご活用ください。今後は、SCS 評価制度の取得支援を行う専門家も掲載予定です。

                         https://www.ipa.go.jp/security/sme/shien/list.html

 取引先とのパートナーシップ構築促進に向けた想定事例及び解説

協力してセキュリティ対策と価格交渉を進める事例及び解説文書を公開しています。
